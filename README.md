# Shadow Zoo

เกมต่อสู้สัตว์ 2D แบบตู้เกมอาร์เคด เล่นบนเว็บด้วย Phaser 3, TypeScript และ Vite ภาพพิกเซลพื้นฐาน 384 × 224 พร้อมฉากสวนสัตว์ยามเย็น เสียงสังเคราะห์ นักสู้สองตัว และหน้าจอเกมที่ใช้พื้นที่เต็มเบราว์เซอร์

## เริ่มเล่น

เปิดเล่นได้ที่ **https://volkyanothai.github.io/shadow-zoo/** ไม่ต้องดาวน์โหลด HTML ติดตั้ง Node.js หรือสมัครบัญชี

จากหน้าไตเติล กด **START GAME → ARCADE** เลือก **LEO** สิงโตที่เร็ว หรือ **KOBA** กอริลลาที่โจมตีหนัก แล้วกด **FIGHT** เพื่อสู้กับ CPU ชนะสองยกเพื่อชนะแมตช์ ยกละ 60 วินาที

เกมมีหน้าไตเติล เมนูหลัก หน้าเลือกนักสู้ เมนูหยุดเกม **SETTINGS**, **HOW TO PLAY** และหน้าผลการแข่งขัน ใช้ปุ่มลูกศรเลือกเมนู **Enter** ยืนยัน และ **Escape** ย้อนกลับหรือหยุดเกม เมนูหยุดเกมให้เล่นต่อ เริ่มแมตช์ใหม่ เปลี่ยนนักสู้ หรือกลับเมนูหลักได้ มือถือมีปุ่มสัมผัสสำหรับเคลื่อนที่และโจมตี

เว็บไซต์เผยแพร่ผ่าน GitHub Pages แล้ว การเปลี่ยนแปลงใหม่จะปรากฏหลังเผยแพร่ `gh-pages` รอบถัดไป ดู [วิธีอัปเดตเว็บไซต์](docs/deployment.md) สำหรับผู้พัฒนา

## การควบคุม

| ปุ่ม | การกระทำ |
| --- | --- |
| ปุ่มลูกศรในเมนู / A หรือ D ที่หน้าเลือกนักสู้ | เลือกเมนู / นักสู้ |
| A / D หรือ ← / → | เดินซ้าย / ขวา |
| W หรือ ↑ | กระโดด |
| S หรือ ↓ | ย่อตัว |
| กดทิศทางถอยจากคู่ต่อสู้ | ป้องกัน; ย่อและถอยเพื่อป้องกันท่าต่ำ |
| U / I / O | ต่อยเบา / กลาง / หนัก |
| J / K / L | เตะเบา / กลาง / หนัก |
| Q | ท่าพิเศษ 1: Leo พุ่งตะปบ / Koba หมัดพุ่ง |
| E | ท่าพิเศษ 2: Leo คลื่นคำราม / Koba คลื่นทุบพื้น |
| R | ท่าไม้ตาย เมื่อเกจ SUPER เต็ม |
| P | หยุด / เล่นต่อระหว่างการแข่งขัน |
| Escape | ย้อนกลับในเมนู / หยุดเกมระหว่างการแข่งขัน |
| Enter | ยืนยันเมนู / เริ่มแข่ง / เล่นต่อเมื่อหยุดอยู่ |

ใช้คำสั่งทิศทางแทนปุ่มลัดได้: **↓ ↘ → + ต่อย** สำหรับท่าพิเศษ 1, **↓ ↙ ← + ต่อย** สำหรับท่าพิเศษ 2 และ **↓ ↘ → ↓ ↘ → + ต่อย** สำหรับท่าไม้ตาย ทิศทางทั้งหมดอ้างอิงการหันหน้าของนักสู้

คอมโบเกิดจากการโจมตีที่โดนแล้วต่อท่าที่แรงขึ้นระหว่างคู่ต่อสู้ยังชะงัก ลอง **U → I → Q** หรือ **J → K → E** ในระยะประชิด โดยกดท่าถัดไปหลังเห็นท่าก่อนหน้าโดน ท่าปกติสามารถต่อไปท่าพิเศษหรือท่าไม้ตายได้ เกจสะสมจากการโจมตีโดน การป้องกัน และการรับความเสียหาย

## พัฒนาและตรวจสอบ

ใช้ Node.js 22.12 ขึ้นไป (พัฒนาและทดสอบด้วย Node.js 24)

```sh
npm ci
npm run dev
```

Vite จะแสดง URL สำหรับเปิดเกมระหว่างพัฒนา สำหรับทดสอบระบบและตรวจไฟล์เว็บไซต์ที่ build แล้ว:

```sh
npm test
npm run build
npm run preview
```

ไฟล์เว็บไซต์ที่พร้อมเผยแพร่อยู่ใน `dist/` การเผยแพร่ GitHub Pages ใช้ไฟล์ที่ build แล้วบน branch `gh-pages` จึงไม่ต้องให้ผู้เล่นรันคำสั่งเหล่านี้

ชุดทดสอบตรวจช่วงออกท่า ความเสียหาย การป้องกัน คอมโบ โปรเจกไทล์ เกจท่าไม้ตาย รอบการแข่งขัน และ CPU แบบทำซ้ำได้ ระบบจำลองทำงานที่ 60 Hz แยกจากการวาดภาพ ตัวเกมหยุดอัตโนมัติเมื่อสลับแท็บ

## โครงสร้าง

- `src/combat.ts`: ระบบต่อสู้และ CPU
- `src/art.ts`: สไปรต์พิกเซลพร้อมท่าทางและเอฟเฟกต์
- `src/game.ts`: Phaser การวาดสนาม HUD และวงรอบเกม
- `src/input.ts`: คีย์บอร์ด ปุ่มสัมผัส และคำสั่งทิศทาง
- `src/audio.ts`: เพลงและเสียงอาร์เคดผ่าน Web Audio
- `src/main.ts` / `src/style.css`: หน้าไตเติล เมนูหลัก เลือกนักสู้ และ UI เต็มพื้นที่เบราว์เซอร์
- `public/assets/arena.png`: ฉากพิกเซลต้นฉบับที่สร้างขึ้นสำหรับเกมนี้
- `public/assets/title.png`: ภาพหน้าไตเติลของเกม

เวอร์ชันนี้เป็นเกมผู้เล่นหนึ่งคนสู้กับ CPU นักสู้สองตัว ฉากเดียว ยังไม่มีออนไลน์หรือการบันทึกอันดับ
