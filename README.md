# Shadow Zoo

เกมต่อสู้สัตว์ 2D แบบตู้เกมอาร์เคด เล่นบนเว็บด้วย Phaser 3, TypeScript และ Vite ภาพพิกเซลพื้นฐาน 384 × 224 พร้อมนักสู้หกตัว สี่สังเวียน เสียงสังเคราะห์ และหน้าจอเกมที่ใช้พื้นที่เต็มเบราว์เซอร์ ซอร์สเวอร์ชันนี้รองรับภาษาไทยและอังกฤษ

## เริ่มเล่น

เปิดเล่นได้ที่ **https://volkyanothai.github.io/shadow-zoo/** ไม่ต้องดาวน์โหลด HTML ติดตั้ง Node.js หรือสมัครบัญชี

จากหน้าเข้าเกม กด **เข้าเกม → อาร์เคด** เลือกนักสู้ ยืนยันเพื่อไปหน้า **เลือกสังเวียน** แล้วกด **เริ่มต่อสู้!** เพื่อสู้กับ CPU ชนะสองยกเพื่อชนะแมตช์ ยกละ 60 วินาที หากใช้ภาษาอังกฤษ ลำดับคือ **START GAME → ARCADE → CHOOSE ARENA → FIGHT!**

เกมมีหน้าเข้าเกม เมนูหลัก หน้าเลือกนักสู้และสังเวียน เมนูพักเกม **ตั้งค่า / SETTINGS**, **วิธีเล่น / HOW TO PLAY** และหน้าผลการแข่งขัน ใช้ปุ่มลูกศรเลือกเมนู **Enter** ยืนยัน และ **Escape** ย้อนกลับหรือพักเกม เมนูพักเกมให้เล่นต่อ เริ่มแมตช์ใหม่ เปลี่ยนนักสู้ หรือกลับเมนูหลักได้ มือถือมีปุ่มสัมผัสสำหรับเคลื่อนที่และโจมตี

กด **ไทย / EN** หรือเลือกภาษาในเมนูตั้งค่าเพื่อเปลี่ยนภาษาได้ทันที ทั้งเมนู คู่มือ HUD และผลการแข่งขัน ภาษาเริ่มต้นเป็นไทย และเกมจดจำภาษาที่เลือกบนเบราว์เซอร์เมื่อมีพื้นที่เก็บข้อมูล ฟอนต์ไทยอยู่ในไฟล์เกม ไม่ต้องโหลดจากบริการฟอนต์ภายนอก การเปลี่ยนภาษาไม่เริ่มแมตช์ใหม่

เว็บไซต์เผยแพร่ผ่าน GitHub Pages แล้ว การเปลี่ยนแปลงใหม่จะปรากฏหลังเผยแพร่ `gh-pages` รอบถัดไป ดู [วิธีอัปเดตเว็บไซต์](docs/deployment.md) สำหรับผู้พัฒนา

## นักสู้และสังเวียน

| นักสู้ | สไตล์ | ท่าพิเศษ Q / E / ไม้ตาย R |
| --- | --- | --- |
| ลีโอ / LEO — สิงโต | สมดุลและแม่นยำ | กรงเล็บพุ่ง / คำรามราชัน / พิโรธจ้าวป่า |
| โคบา / KOBA — กอริลลา | หมัดหนักและกดดัน | หมัดเหล็กพุ่ง / ทุบแผ่นดิน / ปฐพีสะเทือน |
| รายา / RAYA — เสือ | รวดเร็วและต่อคอมโบ | พยัคฆ์โผน / เขี้ยวเพลิง / ลายเสือคลั่ง |
| เป่า / BAO — แพนด้า | ฝ่ามือและคุมระยะ | ฝ่ามือหยก / คลื่นไผ่ / พายุหยก |
| ไนโล / NILO — จระเข้ | ระยะไกลและท่าต่ำ | เขี้ยวแม่น้ำ / คลื่นบึง / พายุหางจระเข้ |
| รัค / RUK — แรด | พลังหนักและพุ่งชน | นอทะลวง / คลื่นกระแทก / สายฟ้าถล่ม |

นักสู้มีความเร็ว ระยะโจมตี และจังหวะออกท่าต่างกัน CPU สุ่มนักสู้จากตัวอื่นในรายชื่อ เล่นซ้ำหรือเริ่มแมตช์ใหม่จะคงคู่ต่อสู้และสังเวียนที่เลือกไว้

เลือกได้สี่ฉาก: **วิหารยามสนธยา / Nightfall Sanctuary**, **ป่าไผ่ใต้แสงจันทร์ / Moonlit Bamboo**, **ทุ่งสะวันนาสีทอง / Savanna Sunset** และ **ซากวิหารป่าชายเลน / Mangrove Ruins** แต่ละฉากมีภาพพิกเซลและบรรยากาศของตัวเอง

## การควบคุม

| ปุ่ม | การกระทำ |
| --- | --- |
| ปุ่มลูกศรในเมนู | เลือกเมนู / นักสู้ / สังเวียน |
| A / D หรือ ← / → | เดินซ้าย / ขวา |
| W หรือ ↑ | กระโดด |
| S หรือ ↓ | ย่อตัว |
| กดทิศทางถอยจากคู่ต่อสู้ | ป้องกัน; ย่อและถอยเพื่อป้องกันท่าต่ำ |
| U / I / O | ต่อยเบา / กลาง / หนัก |
| J / K / L | เตะเบา / กลาง / หนัก |
| Q | ท่าพิเศษ 1 ของนักสู้ที่เลือก |
| E | ท่าพิเศษ 2 ของนักสู้ที่เลือก |
| R | ท่าไม้ตาย เมื่อเกจ SUPER เต็ม |
| P | หยุด / เล่นต่อระหว่างการแข่งขัน |
| Escape | ย้อนกลับในเมนู / หยุดเกมระหว่างการแข่งขัน |
| Enter | ยืนยันเมนู / เริ่มแข่ง / เล่นต่อเมื่อหยุดอยู่ |

ใช้คำสั่งทิศทางแทนปุ่มลัดได้: **↓ ↘ → + ต่อย** สำหรับท่าพิเศษ 1, **↓ ↙ ← + ต่อย** สำหรับท่าพิเศษ 2 และ **↓ ↘ → ↓ ↘ → + ต่อย** สำหรับท่าไม้ตาย ทิศทางทั้งหมดอ้างอิงการหันหน้าของนักสู้

คอมโบเกิดจากการโจมตีที่โดนแล้วต่อท่าที่แรงขึ้นระหว่างคู่ต่อสู้ยังชะงัก ลอง **U → I → Q** หรือ **J → K → E** ในระยะประชิด โดยกดท่าถัดไปหลังเห็นท่าก่อนหน้าโดน ท่าปกติสามารถต่อไปท่าพิเศษหรือท่าไม้ตายได้ เกจสะสมจากการโจมตีโดน การป้องกัน และการรับความเสียหาย

## พัฒนาและตรวจสอบ

ใช้ Node.js 22.12 ขึ้นไป (พัฒนาและทดสอบด้วย Node.js 24)

```sh
npm ci
npm run dev
```

Vite จะแสดง URL สำหรับเปิดเกมระหว่างพัฒนา สำหรับทดสอบระบบและตรวจไฟล์เว็บไซต์ที่ build แล้ว:

```sh
npm test
npm run build
npm run preview
```

ไฟล์เว็บไซต์ที่พร้อมเผยแพร่อยู่ใน `dist/` การเผยแพร่ GitHub Pages ใช้ไฟล์ที่ build แล้วบน branch `gh-pages` จึงไม่ต้องให้ผู้เล่นรันคำสั่งเหล่านี้

ชุดทดสอบตรวจช่วงออกท่า ความเสียหาย การป้องกัน คอมโบ โปรเจกไทล์ เกจท่าไม้ตาย รอบการแข่งขัน และ CPU แบบทำซ้ำได้ ระบบจำลองทำงานที่ 60 Hz แยกจากการวาดภาพ ตัวเกมหยุดอัตโนมัติเมื่อสลับแท็บ

## โครงสร้าง

- `src/combat.ts`: ระบบต่อสู้และ CPU
- `src/catalog.ts`: ข้อมูลนักสู้ ท่าพิเศษ สังเวียน และชื่อสองภาษา
- `src/i18n.ts`: ข้อความภาษาไทยและอังกฤษ การสลับภาษาและจดจำภาษา
- `src/art.ts`: สไปรต์พิกเซลพร้อมท่าทางและเอฟเฟกต์
- `src/game.ts`: Phaser การวาดสนาม HUD และวงรอบเกม
- `src/input.ts`: คีย์บอร์ด ปุ่มสัมผัส และคำสั่งทิศทาง
- `src/audio.ts`: เพลงและเสียงอาร์เคดผ่าน Web Audio
- `src/main.ts` / `src/style.css`: หน้าเข้าเกม เมนูหลัก เลือกนักสู้และสังเวียน และ UI เต็มพื้นที่เบราว์เซอร์
- `public/assets/arena.png`: ฉากพิกเซลต้นฉบับที่สร้างขึ้นสำหรับเกมนี้
- `public/assets/stage-*.png`: ฉากป่าไผ่ สะวันนา และป่าชายเลน
- `public/assets/title.png`: ภาพหน้าไตเติลของเกม

เวอร์ชันนี้เป็นเกมผู้เล่นหนึ่งคนสู้กับ CPU นักสู้หกตัว สี่ฉาก ยังไม่มีออนไลน์หรือการบันทึกอันดับ
