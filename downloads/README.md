# เล่น Shadow Zoo

ดาวน์โหลด `shadow-zoo-play.zip` จากโฟลเดอร์นี้ โดยเปิดหน้าไฟล์บน GitHub แล้วกด **Download raw file** หรือ **View raw**

1. แตก ZIP
2. เปิด `shadow-zoo.html` ด้วย Chrome หรือ Edge บนคอมพิวเตอร์
3. เลือก LEO หรือ KOBA แล้วกด **ENTER THE ARENA**

ไฟล์รวมโค้ด ภาพ และฟอนต์แล้ว ไม่ต้องติดตั้ง Node.js หรือใช้เซิร์ฟเวอร์ เสียงเริ่มเมื่อกดเล่น

**WASD** / ลูกศร: เคลื่อนที่ · **U I O**: ต่อย · **J K L**: เตะ · **Q E**: ท่าพิเศษ · **R**: ท่าไม้ตายเมื่อเกจเต็ม · **P**: หยุด/เล่นต่อ

เกมเวอร์ชันแรกมีนักสู้สองตัว ฉากเดียว และคู่ต่อสู้ CPU ชนะสองยกเพื่อชนะแมตช์
