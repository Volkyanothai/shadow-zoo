# Shadow Zoo 0.1 — Android test build

ไฟล์ `shadow-zoo-0.1.0.apk` เป็นเกมเวอร์ชันทดสอบ ขนาดประมาณ 29 MB

ดาวน์โหลด APK แล้วเปิดไฟล์บนแท็บเล็ตเพื่อติดตั้ง จากนั้นเปิด Shadow Zoo ในแนวนอน แล้วแตะ ENTER THE ARENA

ตัวเกมมีเสือสู้กับหมาป่าบอต เล่นออฟไลน์ มีปุ่มสัมผัสและระบบโจมตี ป้องกัน กระโดด และหลบ

ต้องใช้ระบบที่ติดตั้ง Android APK ได้, ARM64, Android 7 ขึ้นไป และ OpenGL ES 3.0

ผ่านการทดสอบระบบเกม 25 ข้อและตรวจลายเซ็น APK แล้ว ยังไม่ได้ทดสอบการติดตั้งหรือ FPS บน MatePad จริง

โค้ดเกมอยู่ในสาขาเดียวกัน เปิด project.godot ด้วย Godot 4.6.3 ได้

ไฟล์เกมลงนามด้วย debug key สำหรับการทดสอบ ตรวจ SHA-256 ได้จาก SHA256SUMS.txt
