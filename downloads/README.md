# Shadow Zoo 0.4 — Fighting animation study

**[ดาวน์โหลด shadow-zoo-0.4.0.apk](shadow-zoo-0.4.0.apk?raw=true)** ปรับท่าการ์ดและเพิ่มแอนิเมชันเสือ 3D รวม 9 ท่า

**[ดูภาพและคำอธิบาย](../docs/model-study.md)** · **[ดูหรือดาวน์โหลดคลิปท่าใหม่](tiger-fight-demo.mp4?raw=true)**

เปิดเกมแล้วแตะ **3D MOTION STUDY** → **FIGHT DEMO** หรือเลือก **GUARD / STEP FORWARD / STEP BACK / JAB / CROSS / HOOK / BLOCK / DODGE / HIT REACT** ใช้ ORBIT แล้วลากตัวละครเพื่อหมุนตรวจรอบตัว ดูช้าด้วย SPEED และหยุดด้วย PAUSE ได้

รุ่นนี้ใช้แพ็กเกจและกุญแจทดสอบเดิม พร้อมเลขเวอร์ชัน 4 สำหรับอัปเดตทับรุ่นก่อน สนามต่อสู้ยังใช้เสือภาพวาดของ 0.2 ระหว่างตรวจแอนิเมชันสามมิติ

ขนาดประมาณ 32 MB ผ่านการทดสอบรวม 220 ข้อ ตรวจลายเซ็น v2/v3 และการจัดแนว APK 16 KB แล้ว ยังต้องลองความลื่นและการสัมผัสของรุ่นนี้บน MatePad จริง

ดาวน์โหลด [GLB พร้อม 9 ท่า](../assets/fighters/tiger3d/tiger-study.glb?raw=true) หรือ [ต้นฉบับ Blender](tiger-study.blend?raw=true) ได้ ดู [เกมตัวอย่างที่ใช้ศึกษาท่า](../docs/fighting-animation-references.md)

## เวอร์ชัน 0.3

**[ดาวน์โหลด shadow-zoo-0.3.0.apk](shadow-zoo-0.3.0.apk?raw=true)** เพิ่มหน้าดูโมเดลเสือสามมิติสีเทา

ขนาดประมาณ 32 MB

**[ดูภาพและคำอธิบาย](../docs/model-study.md)** · **[ดูหรือดาวน์โหลดคลิปโมเดล](tiger-3d-demo.mp4?raw=true)**

เปิดเกมแล้วแตะ **3D MOTION STUDY** เลือกท่ายืน ก้าวหน้า ก้าวถอย หรือหมัด เลือก ORBIT แล้วลากตัวละครเพื่อหมุนดู ใช้ SPEED ดูช้าและ PAUSE / REPLAY ดูท่าซ้ำได้ การต่อสู้ในสนามยังใช้เสือภาพวาดของ 0.2

เวอร์ชัน 0.3 ใช้แพ็กเกจและกุญแจทดสอบเดิม พร้อมเพิ่มเลขเวอร์ชันเพื่อรองรับการอัปเดตทับรุ่นก่อน ผ่านการทดสอบรวม 131 ข้อ ตรวจลายเซ็นและการจัดแนว APK แล้ว ยังต้องทดลองความลื่นและการสัมผัสของเวอร์ชันนี้บน MatePad จริง

โมเดลยังเป็นงานสีเทาสำหรับตรวจท่า ต้องปรับผิวบริเวณไหล่/สะโพกและรายละเอียดงานศิลป์ต่อ ดาวน์โหลด [GLB](../assets/fighters/tiger3d/tiger-study.glb?raw=true) หรือ [ต้นฉบับ Blender](tiger-study.blend?raw=true) ได้

## เวอร์ชัน 0.2

**[ดาวน์โหลด shadow-zoo-0.2.0.apk](shadow-zoo-0.2.0.apk?raw=true)** เป็นเกมเวอร์ชันทดสอบที่เพิ่มเสือภาพละเอียดและหน้าดูตัวละคร

ขนาดประมาณ 32 MB

**[ดูภาพจากเกมจริง](../docs/visual-study.md)** · **[ดูหรือดาวน์โหลดคลิป](tiger-demo.mp4?raw=true)**

ดาวน์โหลด APK แล้วเปิดไฟล์บนแท็บเล็ตเพื่อติดตั้ง จากนั้นเปิด Shadow Zoo ในแนวนอน แล้วแตะ ENTER THE ARENA

แตะ PREVIEW KAI ในหน้าแรกเพื่อดูเสือขยาย เลือก STANCE / WALK / COMBO / GUARD ได้ เวอร์ชันนี้ใช้รหัสแพ็กเกจและกุญแจทดสอบเดิม พร้อมเพิ่มเลขเวอร์ชัน จึงรองรับการอัปเดตทับ 0.1 โดย Android ที่รองรับ APK

ตัวเกมมีเสือสู้กับหมาป่าบอต เล่นออฟไลน์ มีปุ่มสัมผัสและระบบโจมตี ป้องกัน กระโดด และหลบ

ต้องใช้ระบบที่ติดตั้ง Android APK ได้, ARM64, Android 7 ขึ้นไป และ OpenGL ES 3.0

ผ่านการทดสอบระบบเกม 25 ข้อและงานภาพ 56 ข้อ พร้อมตรวจลายเซ็น APK และการจัดแนว 16 KB แล้ว ยังไม่ได้ทดสอบการติดตั้งหรือ FPS ของ 0.2 บน MatePad จริง หมาป่ายังใช้ภาพต้นแบบเดิม

โค้ดเกมอยู่ในสาขาเดียวกัน เปิด project.godot ด้วย Godot 4.6.3 ได้

ไฟล์เกมลงนามด้วย debug key สำหรับการทดสอบ ตรวจ SHA-256 ได้จาก SHA256SUMS.txt

ไฟล์ `shadow-zoo-0.1.0.apk` เก็บไว้สำหรับเวอร์ชันก่อนหน้า
