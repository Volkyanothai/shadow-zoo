# Shadow Zoo 0.2 — Android test build

**[ดาวน์โหลด shadow-zoo-0.2.0.apk](shadow-zoo-0.2.0.apk?raw=true)** เป็นเกมเวอร์ชันทดสอบที่เพิ่มเสือภาพละเอียดและหน้าดูตัวละคร

ขนาดประมาณ 32 MB

**[ดูภาพจากเกมจริง](../docs/visual-study.md)** · **[ดูหรือดาวน์โหลดคลิป](tiger-demo.mp4?raw=true)**

ดาวน์โหลด APK แล้วเปิดไฟล์บนแท็บเล็ตเพื่อติดตั้ง จากนั้นเปิด Shadow Zoo ในแนวนอน แล้วแตะ ENTER THE ARENA

แตะ PREVIEW KAI ในหน้าแรกเพื่อดูเสือขยาย เลือก STANCE / WALK / COMBO / GUARD ได้ เวอร์ชันนี้ใช้รหัสแพ็กเกจและกุญแจทดสอบเดิม พร้อมเพิ่มเลขเวอร์ชัน จึงรองรับการอัปเดตทับ 0.1 โดย Android ที่รองรับ APK

ตัวเกมมีเสือสู้กับหมาป่าบอต เล่นออฟไลน์ มีปุ่มสัมผัสและระบบโจมตี ป้องกัน กระโดด และหลบ

ต้องใช้ระบบที่ติดตั้ง Android APK ได้, ARM64, Android 7 ขึ้นไป และ OpenGL ES 3.0

ผ่านการทดสอบระบบเกม 25 ข้อและงานภาพ 56 ข้อ พร้อมตรวจลายเซ็น APK และการจัดแนว 16 KB แล้ว ยังไม่ได้ทดสอบการติดตั้งหรือ FPS ของ 0.2 บน MatePad จริง หมาป่ายังใช้ภาพต้นแบบเดิม

โค้ดเกมอยู่ในสาขาเดียวกัน เปิด project.godot ด้วย Godot 4.6.3 ได้

ไฟล์เกมลงนามด้วย debug key สำหรับการทดสอบ ตรวจ SHA-256 ได้จาก SHA256SUMS.txt

ไฟล์ `shadow-zoo-0.1.0.apk` เก็บไว้สำหรับเวอร์ชันก่อนหน้า
