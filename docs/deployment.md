# เว็บไซต์ Shadow Zoo

เปิดเล่นได้ที่ **https://volkyanothai.github.io/shadow-zoo/** เว็บไซต์เผยแพร่ผ่าน GitHub Pages แล้ว ผู้เล่นเปิด URL ได้โดยตรง ไม่ต้องดาวน์โหลด HTML ติดตั้ง Node.js หรือสมัครบัญชี

## เริ่มเล่น

ซอร์สเวอร์ชันใหม่มีนักสู้หกตัวและสี่สังเวียน กด **เข้าเกม → อาร์เคด** เลือกและยืนยันนักสู้ เลือกสังเวียน แล้วกด **เริ่มต่อสู้!** เพื่อแข่งกับ CPU ชนะสองยกเพื่อชนะแมตช์ ภาษาอังกฤษใช้ **START GAME → ARCADE → CHOOSE ARENA → FIGHT!**

หน้าเข้าเกม เมนูหลัก หน้าเลือกนักสู้และสังเวียน และสนามใช้พื้นที่เต็มเบราว์เซอร์ เล่นด้วยคีย์บอร์ดบนคอมพิวเตอร์ หรือปุ่มสัมผัสบนมือถือ ใช้ปุ่มลูกศรเลือกเมนู **Enter** ยืนยัน และ **Escape** ย้อนกลับหรือพักเกม มีเมนูพักเกม **ตั้งค่า / SETTINGS**, **วิธีเล่น / HOW TO PLAY** และหน้าผลการแข่งขัน แชร์ URL เดียวกันให้ผู้เล่นคนอื่นได้

กด **ไทย / EN** หรือเลือกภาษาในเมนูตั้งค่าเพื่อสลับไทยและอังกฤษ เมนู คู่มือ HUD และผลการแข่งขันเปลี่ยนทันทีโดยคงแมตช์เดิม ภาษาเริ่มต้นเป็นไทยและจดจำตัวเลือกในเบราว์เซอร์เมื่อมีพื้นที่เก็บข้อมูล ฟอนต์ไทยรวมอยู่ในไฟล์ที่ build แล้ว

## การตั้งค่า Pages ที่ใช้

ตั้งค่าไว้แล้วใน [Settings → Pages](https://github.com/Volkyanothai/shadow-zoo/settings/pages): **Source → Deploy from a branch**, **Branch → gh-pages**, โฟลเดอร์ **/(root)** ไม่ต้องตั้งค่าใหม่เมื่ออัปเดตเกม

หากตั้งค่า repository ใหม่ ให้ใช้ค่าเดียวกันแล้วกด **Save** GitHub Pages บนแผนฟรีใช้กับ repository แบบ Public

Branch `gh-pages` เก็บไฟล์เว็บไซต์ที่ build แล้ว ส่วน `delivery/shadow-zoo-playable` เก็บซอร์สสำหรับพัฒนา

หากอัปเดตแล้วยังเห็นหน้าเดิม ให้รอการเผยแพร่รอบใหม่เสร็จแล้วรีเฟรช หากเห็นหน้า 404 ให้ตรวจสถานะการเผยแพร่และค่า Source, branch และโฟลเดอร์ใน Pages

## พัฒนาและอัปเดตเว็บไซต์

ใช้ Node.js 22.12 ขึ้นไป:

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`npm run build` สร้างเว็บไซต์ใน `dist/` ตรวจเกมที่ build แล้วด้วย `npm run preview` รวมถึงการสลับภาษา หน้าเลือกนักสู้และสังเวียน และการเริ่มแมตช์ เมื่อต้องการอัปเดตเว็บ ให้นำเนื้อหาใน `dist/` ไปเผยแพร่ที่ root ของ branch `gh-pages` พร้อมไฟล์ `.nojekyll` ภาพฉาก และฟอนต์ทั้งหมด แล้วรอ Pages เผยแพร่รอบใหม่ การแก้ซอร์สอย่างเดียวยังไม่เปลี่ยนเว็บไซต์ที่ผู้เล่นเห็น การตั้งค่านี้ใช้การเผยแพร่จาก branch โดยตรง ไม่ต้องเพิ่ม workflow หรือส่ง credentials ให้ผู้เล่น

Vite ใช้เส้นทาง asset แบบ relative เพื่อให้เว็บทำงานใต้ `/shadow-zoo/` ได้ หลังอัปโหลดให้ตรวจสถานะการเผยแพร่และเปิด URL จริงอีกครั้งก่อนยืนยันว่าเวอร์ชันใหม่พร้อมให้เล่นแล้ว

ดูการควบคุมและคอมโบทั้งหมดใน [README](../README.md#การควบคุม)
