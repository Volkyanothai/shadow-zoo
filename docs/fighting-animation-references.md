# ตัวอย่างที่ใช้ปรับอนิเมชันต่อสู้ของ Kai

ตรวจภาพเฟรมจริงและข้อมูลอนิเมชันจากเกม/ตัวอย่างเกมต่อสู้ที่เข้าถึงได้ เพื่อปรับท่าการ์ด การออกอาวุธ และปฏิกิริยาของเสือ 3D ให้สื่อว่าเป็นนักสู้มากขึ้น ภาพเหล่านี้ใช้ศึกษาท่าทางเท่านั้น ไม่ได้นำสไปรต์ โมเดล หรืออนิเมชันของแหล่งอ้างอิงมาใส่ในเกม

## 1. Sakuga Engine — ตัวอย่างนักสู้ Kaede

ดูภาพท่าเริ่มการ์ด `120-0.png`, การ์ดค้าง `120-2.png`, รับแรงขณะบล็อก `120-1.png`, บล็อกกลางอากาศ `122-0.png`, ท่าโจมตี `200-0.png` ถึง `200-3.png` และตัวอย่างเฟรมยืน `0-1/3/6/9/12.png` พร้อมตรวจชื่อและเวลาอนิเมชันในฉากจริง

- [ภาพการ์ดค้าง](https://github.com/NoisyChain/Sakuga-Engine/blob/d54581b131ef2a1f6b8511a79c74ea37168c31b1/Fighters/Kaede/Sprites/120-2.png)
- [ภาพรับแรงขณะบล็อก](https://github.com/NoisyChain/Sakuga-Engine/blob/d54581b131ef2a1f6b8511a79c74ea37168c31b1/Fighters/Kaede/Sprites/120-1.png)
- [ภาพช่วงออกอาวุธ](https://github.com/NoisyChain/Sakuga-Engine/blob/d54581b131ef2a1f6b8511a79c74ea37168c31b1/Fighters/Kaede/Sprites/200-1.png)
- [ฉากและเวลาแต่ละเฟรม](https://github.com/NoisyChain/Sakuga-Engine/blob/d54581b131ef2a1f6b8511a79c74ea37168c31b1/Fighters/Kaede/Instances/Fighter_Kaede.tscn)

สิ่งที่เห็นจริงคือการ์ดเปลี่ยนแนวแขนมาปิดบริเวณหน้าและคาง อกหมุน ขาแยกและเข่างอ การรับแรงขณะบล็อกยังรักษาทรงการ์ดไว้ ส่วนเฟรมยืนเปลี่ยนระดับตัว เข่า และรายละเอียดแขนเสื้อเล็กน้อย ท่าโจมตีมีภาพเตรียม ภาพยืดอาวุธ และภาพเก็บกลับที่แยกอ่านออก

ข้อมูลฉากยืนยันว่า `Block_Neutral_Enter` ยาว 0.1 วินาที และแยก `Blocking_Neutral` ออกจาก `Blockstun_Neutral` ท่า `5A` ยาวประมาณ 0.233 วินาที เปลี่ยนจากภาพเตรียมไปภาพยืดที่ 0.05 วินาที ก่อนกลับภาพยืนที่ท้ายท่า ขณะที่ `5B` ยาว 0.4 และ `5C` ประมาณ 0.667 วินาที ตัวเลขนี้เป็นข้อมูลของตัวอย่าง Kaede ไม่ใช่ค่าจาก Shadow Fight และไม่ได้ยกมาใช้กับ Kai โดยตรง

โค้ดเอนจินระบุ [MIT](https://github.com/NoisyChain/Sakuga-Engine/blob/d54581b131ef2a1f6b8511a79c74ea37168c31b1/LICENSE) การศึกษาครั้งนี้ไม่อ้างว่าสิทธิของภาพตัวละครทุกชิ้นเท่ากับสิทธิของโค้ด และไม่แจกจ่ายภาพเหล่านี้ร่วมกับ Shadow Zoo

## 2. Fish Folk: Punchy — สัตว์ในเกม beat-em-up

ดูสไปรต์ชีตจริงของ Brute, Fishy, Sharky และ Bandit พร้อมอ่านไฟล์ข้อมูลนักสู้ที่กำหนดช่วงเฟรม

- [Brute: ภาพยืน โจมตี โดนตี และล้ม](https://github.com/fishfolk/punchy/blob/ab48fe1545bba2c9bc8d0c971d8d7fc4efd7f74e/assets/fighters/brute/brute_base_64_80.png)
- [ข้อมูลเฟรมของ Brute](https://github.com/fishfolk/punchy/blob/ab48fe1545bba2c9bc8d0c971d8d7fc4efd7f74e/assets/fighters/brute/brute.fighter.yaml)
- [Fishy: เฟรมยืนและการกะพริบตา](https://github.com/fishfolk/punchy/blob/ab48fe1545bba2c9bc8d0c971d8d7fc4efd7f74e/assets/fighters/fishy/fishy_base_96_80.png)

Brute ใช้เฟรม 0–3 สำหรับยืน 16–23 สำหรับต่อย 32–34 สำหรับโดนตี และ 40–46 สำหรับล้ม ภาพต่อยเปลี่ยนจากแขนหดไปแขนยื่นและเก็บกลับ ปฏิกิริยาโดนตีและล้มมีทรงตัวคนละแบบ ส่วน Fishy/Sharky มีการเปลี่ยนตาเฉพาะบางเฟรมของช่วงยืน ไม่ได้ขยับทุกส่วนแรงเท่ากันตลอดเวลา

สัตว์ในเกมนี้มีแขนขาสั้น จึงใช้ดูจังหวะและการแยกอารมณ์ของท่า ไม่ใช้เป็นแม่แบบสัดส่วนหรือการ์ดของเสือ ตัวเกมระบุว่าเป็น beat-em-up 2.5D; สื่อระบุ [CC BY-NC 4.0](https://github.com/fishfolk/punchy/blob/ab48fe1545bba2c9bc8d0c971d8d7fc4efd7f74e/LICENSE.md) โดย The Fish Folk Game & Spicy Lobster Developers

## สิ่งที่นำมาปรับกับเสือ 3D

ข้อเสนอต่อไปนี้เป็นการออกแบบ Kai จากสิ่งที่ตรวจเห็น ร่วมกับหลักการเคลื่อนไหวทั่วไป ไม่ใช่การคัดลอกท่าของตัวละครอ้างอิง

| ส่วนที่ปรับ | เป้าหมายที่ตรวจด้วยภาพได้ |
| --- | --- |
| ท่าพร้อมสู้ | มือหน้าออกนำ มือหลังใกล้แก้ม ศอกต่ำกว่ากำปั้น คางลดลง อกและสะโพกเหลื่อมกัน เท้าวางหน้า–หลังและเข่างอ |
| ชีวิตขณะยืน | หายใจและถ่ายน้ำหนักเล็กน้อย ศีรษะยังมองคู่ต่อสู้ แขนไม่ตกจากการ์ด หางขยับตามลำตัวช้ากว่าเล็กน้อย |
| หมัดแย็บ | เตรียมสั้น พุ่งเร็ว เก็บกลับการ์ด มืออีกข้างคุ้มหน้า ลำตัวช่วยส่งแรง |
| หมัดหลังและฮุก | แนวหมัดและการหมุนอกต่างจากแย็บ มีแรงจากสะโพกและขารับน้ำหนัก จังหวะเตรียมกับคืนตัวต่างกัน |
| บล็อก | แขนปิดหน้าและลำตัวให้แน่นขึ้น รับแรงด้วยเข่าและอก แล้วคืนท่าการ์ด |
| หลบและย่อ | ศีรษะออกจากแนวโจมตีด้วยเข่า สะโพก และอก มือยังป้องกัน ไม่เอียงทั้งตัวแข็ง ๆ |
| โดนโจมตี | เห็นแรงที่ศีรษะและอกก่อนคืนสมดุล รูปท่าต่างจากบล็อกอย่างชัดเจน |
| เปลี่ยนท่า | ใช้ท่าพร้อมสู้ร่วมกันที่หัวและท้ายท่า พร้อมผสมช่วงเปลี่ยนท่าเพื่อเลี่ยงการกระตุก |

ต้องตรวจทั้งด้านข้างและมุมเฉียงที่ความเร็วปกติและช้า ดูเท้าสัมผัสพื้น ข้อต่อไม่กลับด้าน มือไม่ทะลุหน้า และการ์ดยังอ่านออกระหว่างขยับ การทดสอบทางเทคนิคช่วยจับข้อผิดพลาดเหล่านี้ได้ แต่ความรู้สึกมีน้ำหนักและความเป็นธรรมชาติยังต้องตัดสินจากภาพเคลื่อนไหว

ข้อจำกัดของแหล่งอ้างอิง: รอบนี้ดูภาพเฟรมที่ดาวน์โหลดได้จริงและอ่านข้อมูลเวลาใน GitHub; คลิป Shadow Fight บน YouTube และ GIF/MP4 ของ Punchy ที่โฮสต์บน `user-images.githubusercontent.com` ถูกเครือข่ายปฏิเสธ จึงไม่ได้อ้างว่าได้ชมคลิปเหล่านั้น
